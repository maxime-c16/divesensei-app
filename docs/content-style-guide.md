# DiveSensei Content Style Guide

## Product terms

- `Session`: one analyzed video review record
- `Attempt`: one proposed dive event
- `Review video`: the browser-safe full-session video used for review
- `Export`: creating clip files from attempts marked `Keep`
- `Diagnostics`: technical artifacts, reports, and logs

## Preferred labels

- `Analyze video`, not `Run analysis`
- `Open`, not `Open session review`
- `Ready for review`, not `Ready now`
- `Preparing review video`, not `Building session proxy`
- `Needs attention`, not `Ready with proxy issue` or `Ready with errors`

## Tone

- Use plain task language
- Prefer sentence case
- Keep buttons short and specific
- Avoid pipeline jargon in primary UI
- Reserve technical details for Diagnostics

## Avoid

- `candidate`, `item`, `local run`, `proxy`, `pipeline`, `artifact` in primary workflow copy
- Exposing detector IDs and profile IDs without translation
- Repeating the same idea with different wording across tabs
