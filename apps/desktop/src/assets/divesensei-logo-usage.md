# DiveSensei Logo Usage

## Files

- `divesensei-mark.svg`
  - Primary standalone mark
- `divesensei-mark-mono.svg`
  - Single-color mark for tiny sizes and constrained surfaces
- `divesensei-app-tile.svg`
  - Rounded app icon tile
- `divesensei-lockup-dark.svg`
  - Icon plus wordmark for dark backgrounds
- `divesensei-lockup-light.svg`
  - Icon plus wordmark for light backgrounds

## When To Use Which

- Use `divesensei-mark.svg`
  - product header icon
  - dashboard chrome
  - splash screens on dark surfaces

- Use `divesensei-mark-mono.svg`
  - favicon-sized placements
  - embossed or one-color print
  - disabled states, watermarks, or low-contrast utility surfaces

- Use `divesensei-app-tile.svg`
  - desktop app icon mockups
  - social preview tiles
  - launchers, store cards, and profile thumbnails

- Use `divesensei-lockup-dark.svg`
  - pitch decks with dark slides
  - website hero/header on dark backgrounds
  - screenshots and product marketing frames

- Use `divesensei-lockup-light.svg`
  - docs
  - PDFs
  - proposals and press assets on white backgrounds

## UI Best Practices

- Prefer the standalone mark when the brand is already named nearby.
- Prefer a lockup on first exposure or on marketing surfaces.
- Do not scale the detailed full-color mark below `24px`.
- Below `24px`, switch to `divesensei-mark-mono.svg`.
- Keep clear space around the logo equal to at least the diver head circle diameter.
- Do not place the dark lockup on busy imagery without a backing surface.
- Do not recolor the full-color mark arbitrarily; use the mono version instead.
